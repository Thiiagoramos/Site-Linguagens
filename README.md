Web app de consulta rápida sobre linguagens de programação. Digite o nome de uma linguagem e obtenha informações sobre sua história, finalidade e paradigmas principais.

---

##  Funcionalidades

-  Busca em tempo real por linguagens de programação
-  Exibe história, finalidade e paradigmas de cada linguagem
-  Interface simples e intuitiva, sem necessidade de back-end

---

##  Estrutura do Projeto

```
Site-Linguagens/
├── index.html       # Estrutura principal da aplicação
├── style.css        # Estilização visual
├── dados.js         # Base de dados das linguagens
└── logica.js        # Lógica de busca e renderização
```

---

##  Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/Thiiagoramos/Site-Linguagens.git
```

2. Abra o arquivo `index.html` diretamente no navegador — nenhuma instalação necessária.

3. Digite o nome de uma linguagem no campo de busca e veja os resultados.
